# PetFam (펫팸)

**바탕화면에 사는 나의 반려동물 가족.**

PetFam은 Windows용 데스크톱 반려동물이에요. 강아지나 고양이를 입양하면 *창 뒤에* 이사 와서 살아요. 바탕화면 그림 위를 돌아다니며 그 풍경을 자기 집으로 삼고, 직접 지어 준 작은 집에서 낮잠을 자고, 일하고 있는 창 가장자리에서 빼꼼 얼굴을 내밀고, 하루하루 함께 자라요.

화면보호기도 아니고 일을 방해하지도 않아요. 펫은 모든 앱 창 아래, 바탕화면 층에서 지내다가 손을 뻗을 때만 앞으로 나와요.

> 현재 단계: 초기 개발(기술 검증). Windows 10 21H2 이상 / Windows 11. macOS 버전은 계획 중이에요.

## PetFam이 특별한 이유

- **배경화면 속에서 살아요.** 배경화면을 읽어서 그림 속 바닥, 물, 양지, 그늘, 진흙, 집까지 찾아내요. 강아지는 호수에 뛰어들었다 몸을 털고, 고양이는 햇볕을 쬐고 웅덩이를 피해요. 배경화면을 바꾸면 몇 초 안에 새 터전에 적응해요.
- **진짜 품종, 진짜 성격.** 강아지 7종, 고양이 7종. 품종마다 생김새, 기질, 습관, 말투가 달라요. 안으면 비명을 지르는 시바, 안기면 축 늘어지는 랙돌, 밥 얘기만 하는 코기, 처음엔 수줍은 러시안 블루.
- **함께 자라요.** 모든 펫은 생후 2개월 아기로 와서, 함께한 날마다 하루씩 자라 청소년, 성체를 지나 의젓한 노령이 돼요. 나이에 따라 몸과 체력, 행동이 달라져요.
- **자기만의 집.** 집을 짓고 꾸미고 누구 집인지 정해 주면, 펫이 문으로 걸어 들어가 자거나 비를 피해요.
- **진짜 날씨.** 사는 곳에 비가 오면 바탕화면에도 비가 와요. 고양이는 비를 피해 뛰어가고, 강아지는 물웅덩이에서 놀고, 지붕에는 눈이 쌓여요.
- **모든 가상 데스크톱.** Windows 가상 데스크톱 사이를 오가며, 데스크톱을 바꾸면 따라오거나 집을 지켜요.
- **다정한 설계.** 숙제도, 죄책감도 없어요. 펫은 죽지 않고, PC 앞에 있기만 해도 유대감이 유지돼요. 전체 화면 앱이나 발표 중에는 조용히 있어요.

## 기능

### 바탕화면에서의 생활
- 펫은 배경화면과 창 사이에 살아요. 창이 덮으면 그냥 그 뒤에 있는 거예요.
- 펫 위에 마우스를 올리면 앞으로 나와 나를 보고, 쓰다듬거나 들어서 옮길 수 있어요.
- **창가 빼꼼:** 호기심 많은 펫은 지금 쓰는 창 뒤로 걸어 들어가 가장자리로 얼굴을 내밀고 나를 봐요.
- 고양이는 움직이는 마우스 포인터를 사냥해요: 웅크리고, 살금살금, 엉덩이 실룩, 덮치기.
- 펫끼리 놀고, 누가 단짝이고 누가 대장인지 기억해요.

### 품종과 페르소나
| 강아지 | | 고양이 | |
|---|---|---|---|
| 포메라니안 | 솜뭉치 수다쟁이 | 코리안 숏헤어 | 골목대장 고등어 |
| 말티즈 | 껌딱지 공주님 | 러시안 블루 | 수줍은 은빛 신사 |
| 토이 푸들 | 영리한 재주꾼 | 브리티시 숏헤어 | 느긋한 곰돌이 |
| 비숑 프리제 | 웃는 솜사탕 | 스코티시 폴드 | 접힌 귀 애교쟁이 |
| 시바견 | 도도한 고집쟁이 | 페르시안 | 우아한 귀족 공주 |
| 웰시 코기 | 짧은 다리 먹보 대장 | 랙돌 | 안기면 녹는 인형 |
| 진돗개 | 의리의 한국 토박이 | 먼치킨 | 짧은 다리 장난꾸러기 |

품종마다 털과 체형, 기질(장난기, 낯가림, 활동량, 집순이), 습관(식욕, 잠, 점프, 물과 눈을 좋아하는지, 비를 싫어하는지), 친해지는 속도, 그리고 인사·배고픔·졸림·쓰다듬기·날씨 등에 쓰는 자기만의 말투가 있어요.

### 돌보기와 유대감
- 펫마다 심즈식 파이 메뉴: 쓰다듬기, 턱 긁어주기, 안아주기, 공놀이, 간식, 밥, 수건으로 닦기, 앉아, 쉬게 하기. 고른 행동은 할 일 목록에 쌓여 차례로 해요.
- 욕구(배고픔, 에너지, 재미, 애정, 청결)와 기분, 가까워질수록 더 많은 것이 열리는 유대감.
- 공은 직접 던져요: 마우스로 공을 잡아 휙 던지면 강아지가 물어 와요.
- 물에 젖고 진흙이 묻고, 몸을 털고 햇볕에 말라요.

### 성장
새끼(0–14일) → 청소년(15–45일) → 성체(46–365일) → 노령(366일~). PC 앞에서 10분 이상 지낸 날만 하루로 세서, PC를 꺼 둔 동안에는 나이를 먹지 않아요. 단계가 오르거나 기념일이 되면 꽃가루와 고깔모자로 축하해요.

### 집
모양, 색, 장식을 골라 집을 세 채까지 지을 수 있어요. 집마다 주인을 정하거나 모두의 집으로 둘 수 있어요. 펫은 문으로 걸어 들어가 문간에 엎드려 밖을 내다보고, 깨면 다시 걸어 나와요.

### 날씨
고른 도시의 실제 날씨를 [Open-Meteo](https://open-meteo.com)에서 받아와요(끌 수 있어요). 물튀김이 생기는 비, 천둥 번개, 쌓였다 녹는 눈, 흐림과 안개. 펫은 성격대로 반응해요.

### 가상 데스크톱
데스크톱마다 자기 배경화면으로 만든 서식지가 있어요. 펫은 화면 한쪽 끝으로 나가 다른 데스크톱 반대쪽 끝으로 들어오고, 데스크톱을 바꾸면 따라오거나(혹은 돌아다니거나, 집을 지키거나), 트레이에서 불러올 수 있어요.

### 언어
기본은 영어, 한국어는 선택(트레이 → Language / 언어). 품종 소개와 펫 말투까지 모두 바뀌어요.

## 시작하기

필요한 것: Windows 10 21H2 이상(Windows 11 권장), [.NET 8 SDK](https://dotnet.microsoft.com/download).

```
dotnet build
dotnet run --project src/PetFam.App
```

PetFam은 메인 창이 없고 시스템 트레이에 살아요. 처음 실행하면 입양 창이 열려요: 강아지나 고양이를 고르고, 품종을 고르고, 아기에게 이름을 지어 입양하세요.

### 사용법
- **트레이 메뉴:** 우리 아이들(어디 있는지, 불러오기, 이동 모드), 날씨, 밥그릇 놓기, 집 짓기, 펫 추가하기, 언어, 종료.
- **마우스:** 펫 위에 올리면 앞으로 나와요. 클릭하면 메뉴, 누른 채 문지르면 쓰다듬기, 끌면 옮기기. 집은 클릭하면 꾸미기, 끌면 옮기기.
- **패널:** 펫을 클릭하면 기분, 욕구, 유대감, 나이, 할 일 목록이 보이는 패널이 열려요.

## 개인정보
- 창의 위치, 마우스 위치, 자리 비움 시간만 읽어요. 창 안의 내용은 절대 읽지 않아요.
- 배경화면 분석은 내 PC 안에서만 해요. 아무것도 올리지 않아요.
- 네트워크 요청은 선택 기능인 날씨 조회뿐이고, 고른 도시의 좌표만 보내요(IP 위치 조회나 위치 권한 없음). 트레이에서 끌 수 있어요.

## 개발자용

```
dotnet build PetFam.sln
dotnet test
```

```
src/PetFam.Core              플랫폼 독립: 펫, 품종, 욕구, 유대감, 성장, 서식지, 행동, 날씨, 저장
src/PetFam.Platform.Windows  Win32: WorkerW 바탕화면 층, 클릭 통과, 포그라운드 창, 가상 데스크톱
src/PetFam.Platform.MacOS    스텁(계획 중)
src/PetFam.App               Avalonia 앱: 창, 트레이, 3D(SkSL SDF)·벡터 렌더러, 날씨 서비스
tests/PetFam.Core.Tests      xUnit
docs/PLANNING.ko.md          제품·기술 기획서
```

- 데이터: `%LOCALAPPDATA%\PetFam\save.json`(1분마다와 종료할 때 저장), 로그 `petfam.log`, 스냅샷과 확인용 그림. 예전 `ZooZoo` 폴더의 데이터는 처음 실행할 때 복사해 와요.
- 프레임 타이밍: 애니메이션이 버벅이면 `petfam.log`에 무엇에 시간이 걸렸는지 `Hitch:` 줄이 남아요.

### 진단용 환경 변수

| 변수 | 효과 |
|---|---|
| `PETFAM_NO_PEEK=1` | 빼꼼 비활성 (유대 단계 게이트 적용) |
| `PETFAM_CALM_FPS=<n>` | 유휴 프레임레이트 (기본 12) |
| `PETFAM_PAINT_WALLPAPER=1` | 뒷마당 창에 월페이퍼를 직접 그림 (투명이 안 될 때 폴백) |
| `PETFAM_NO_ATTACH=1` | WorkerW에 붙이지 않고 일반 창으로 |
| `PETFAM_RENDER=software\|angle\|wgl` | Avalonia 렌더 백엔드 강제 |
| `PETFAM_COMP=winui\|dcomp\|redirect` | Avalonia 컴포지션 모드 강제 |
| `PETFAM_UI_RENDER=1` | UI 스레드에서 렌더 |
| `PETFAM_SNAPSHOT=1` | 시작 후 뒷마당 스냅샷 자동 저장 (`PETFAM_SNAPSHOT_DELAY=<초>`, 기본 3) |
| `PETFAM_STYLE=fur` | 카툰 대신 털 질감 3D 스타일로 그림 |
| `PETFAM_WALLPAPER=<그림 경로>` | 실제 월페이퍼는 그대로 두고 이 그림을 뒷마당에 깔아 서식지 인식·행동을 시험 |
| `PETFAM_ADOPT=cat,dog,shiba,…` | 시작할 때 펫을 더 데려옴: `cat`·`dog` 또는 품종 id(`pomeranian` `maltese` `poodle` `bichon` `shiba` `corgi` `jindo` `korean-shorthair` `russian-blue` `british-shorthair` `scottish-fold` `persian` `ragdoll` `munchkin`), 저장됨 |
| `PETFAM_SHOW_HABITAT=1` | 인식된 바닥을 초록색, 지평선을 노란 선으로 화면에 표시 (트레이 "(테스트) 서식지 인식 결과 보기"로도 켜고 끔) |
| `PETFAM_BOND=<0~100>` | 시작할 때 모든 펫의 유대감을 이 값으로 설정 (트레이 메뉴 "(테스트) 유대감"으로도 조절 가능) |
| `PETFAM_DEMO_MENU=menu\|queue` | 시작 4초 뒤 첫 펫의 파이 메뉴를 자동으로 열기 (queue: 행동 몇 개를 미리 큐에 넣음) |
| `PETFAM_POSE_SHEET=1` | 시작 시 모든 포즈를 한 장에 그린 `pose-sheet.png` 저장 (리그 확인용) |
| `PETFAM_TURN_SHEET=cat\|dog` | 자세 × 바라보는 방향 10가지를 한 장에 그린 `turn-sheet.png` 저장 (옆·뒷모습 확인용) |
| `PETFAM_MOTION_SHEET=cat\|dog` | 돌아서기·출발·걷기·멈추기·앉기·일어나 달리기를 30fps로 몰아 프레임을 이어 그린 `motion-sheet.png` 저장 (전환 확인용) |
| `PETFAM_DEMO=ball` | 실행 3초 뒤 첫 강아지와 공놀이를 시작 (던지기 확인용) |
| `PETFAM_DEMO=house` | 실행 3초 뒤 새 집 짓기 창을 엶 |
| `PETFAM_DEMO=travel` | 실행 3초 뒤 첫 펫이 옆 데스크톱으로 걸어 나가고, 14초 뒤 다시 불러옴 |
| `PETFAM_BREED_SHEET=1` | 14개 품종을 성체로 두 방향씩 그린 `breed-sheet.png` 저장 |
| `PETFAM_ONBOARDING=1` / `cat` | 시작할 때 입양 창 열기 (`cat`: 고양이 탭) |
| `PETFAM_LANG=en` / `ko` | 그 언어로 시작 (저장된 선택보다 우선) |
| `PETFAM_WEATHER=<날씨>` | 실제 날씨 대신 `clear`·`cloudy`·`fog`·`drizzle`·`rain`·`heavyrain`·`thunder`·`snow`·`heavysnow`(눈이 이미 쌓인 상태로) |
| `PETFAM_DOOR_SHEET=1` | 집에 문으로 들어가는 단계·집 안에서 자는 모습·창 가장자리 엿보기(고양이·강아지, 네 방향)를 그린 `door-sheet.png` 저장 |
| `PETFAM_DEMO=grow` | 실행 4초 뒤 (선택한 펫, 없으면 모든 펫을) 다음 성장 단계로 |
| `PETFAM_AGE_DAYS=<일수>` | 시작할 때 모든 펫의 함께한 날을 이 값으로 |
| `PETFAM_GROWTH_SHEET=1` | 고양이·강아지를 0~500일 나이별로 그린 `growth-sheet.png` 저장 |
| `PETFAM_SAVE=<파일>` | 다른 저장 파일을 사용 (없는 파일이면 첫 실행 온보딩부터, 실제 펫은 그대로) |
