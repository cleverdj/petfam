# PetFam

[English](README.md) | **한국어**

**내 바탕화면에 사는 반려동물 가족.**

PetFam은 Windows와 macOS용 데스크톱 펫이에요. 강아지나 고양이를 입양하면 *창 뒤편*으로 이사 와요. 바탕화면 그림 위를 돌아다니고, 그 풍경을 자기 집처럼 여기고, 직접 지어 준 작은 집에서 낮잠을 자고, 작업 중인 창 가장자리로 빼꼼 얼굴을 내밀고, 하루하루 함께 자라요.

PetFam은 화면 보호기가 아니고 작업을 방해하지도 않아요. 펫들은 모든 앱 창 아래, 바탕화면 층에서 살다가 마우스를 가져갈 때만 앞으로 나와요.

> 상태: 초기 개발 단계. Windows 10 21H2 이상 / Windows 11, 그리고 macOS 11 이상(새로 추가: 빌드와 패키지는 되지만 실제 Mac에서는 아직 시험하지 못했어요).

## 왜 PetFam인가요

- **바탕화면 그림 속에서 살아요.** PetFam은 바탕화면 그림을 읽고 그 안의 바닥, 물, 햇볕 드는 곳, 그늘, 진흙, 집까지 찾아내요. 강아지는 호수에 뛰어들었다가 몸을 털고, 고양이는 일광욕을 하며 물웅덩이를 피해요. 바탕화면을 바꾸면 몇 초 안에 적응해요.
- **진짜 품종, 진짜 성격.** 강아지 17종, 고양이 16종이 저마다 생김새, 기질, 습관, 말투를 가지고 있어요. 안아 올리면 비명을 지르는 시바견, 품에 안기면 축 늘어지는 랙돌, 먹는 얘기만 하는 웰시 코기, 말대꾸하는 허스키, 쉬지 않고 수다 떠는 샴처럼요. 몸도 실제 품종처럼 만들었어요. 골든 리트리버나 메인쿤은 치와와보다 훨씬 크고, 푸들과 비숑은 곱슬곱슬하고, 말티즈의 비단결 털은 바닥까지 내려오고, 포메라니안과 허스키는 목 주변 털이 풍성해요. 허스키는 짙은 머리 무늬와 하얀 얼굴 마스크가 있고, 장모종 고양이는 갈기와 엉덩이 털이 풍성하고, 브리티시 숏헤어는 볼살이 동그랗고, 벵갈은 표범 무늬, 샴은 다리까지 짙은 포인트 색이 있어요. 얼굴도 품종마다 달라요. 닥스훈트의 긴 코와 프렌치 불도그의 납작한 코, 골든 리트리버의 넓은 주둥이와 부드럽게 늘어진 귀, 시바견의 작은 눈과 하얀 눈썹 무늬, 치와와의 크고 동그란 눈, 샴의 짙은 얼굴 마스크와 갸름한 얼굴, 그리고 머리에 리본을 단 말티즈까지요.
- **함께 자라요.** 모든 펫은 생후 두 달 된 새끼로 와서, 함께 보낸 날마다 하루씩 나이를 먹어요. 청소년, 성체를 지나 의젓한 노령까지 자라고, 나이에 따라 몸과 기운, 행동이 달라져요.
- **자기만의 집.** 집을 짓고 꾸미고, 어느 집이 누구 집인지 정해 주세요. 펫이 잠을 자거나 비를 피하러 문으로 들어가는 모습을 볼 수 있어요.
- **실제 날씨.** 사는 곳에 비가 오면 바탕화면에도 비가 와요. 고양이는 비를 피해 뛰어가고, 강아지는 물웅덩이에서 놀고, 지붕에는 눈이 쌓여요.
- **모든 데스크톱과 모니터에서.** 펫이 Windows 가상 데스크톱 사이를 오가요. 데스크톱을 바꾸면 따라오거나 집을 지키고, 모니터에서 옆 모니터로 놀러 가기도 해요.
- **부담 없이.** 해야 할 일도, 죄책감도 없어요. 펫은 절대 죽지 않고, 컴퓨터 앞에 있기만 해도 유대감이 줄지 않아요. 전체 화면 앱이나 발표 중에는 조용히 지내요.

## 기능

### 바탕화면에서의 생활
- 펫은 바탕화면과 창 사이에서 살아요. 창이 펫을 가리면 그냥 그 뒤에 있는 거예요.
- 펫 위에 마우스를 올리면 앞으로 나와 나를 바라보고, 쓰다듬거나 안아 올려서 옮길 수 있어요.
- **창문 빼꼼:** 호기심 많은 펫이 작업 중인 창 뒤로 걸어가서 가장자리로 얼굴을 내밀고 나를 봐요.
- 고양이는 움직이는 마우스 포인터를 사냥해요. 웅크리고, 살금살금 다가가고, 엉덩이를 씰룩이다가 덮쳐요.
- 저마다의 생활: 갑자기 바닥을 우다다 뛰어다니고 나서 헥헥대기(어리고 활발한 품종일수록 자주, 고양이는 밤에), 어지러울 때까지 꼬리 쫓는 강아지, 코를 박고 냄새 따라가기(사냥개와 먹보들이 좋아해요), 하늘의 무언가를 보며 채터링하는 고양이, 배고프면 포인터 아래에서 조르기, 친해지면 포인터를 졸졸 따라오기, 피곤하면 크게 하품하기.
- 장난: 고양이는 눈을 똑바로 쳐다보면서 밥그릇을 밀어 떨어뜨리고, 사용 중인 창 위로 올라가 앉고, 집 지붕 위에서 뒹굴어요. 강아지는 포인터로 달려와 엎드려서 놀자고 조르고, 새로 열린 창을 보고 짖어요(경계심 많은 품종일수록). 둘 다 맑은 날이면 나비를 쫓아 몇 번이고 덮치지만 나비는 늘 도망가요. 고양이는 골골대며 꾹꾹이를 하고, 강아지는 뒷발로 귀를 시원하게 긁어요.
- 펫끼리 함께 놀고, 누가 친구고 누가 대장인지 기억해요.

### 돌보기와 유대감
- 펫마다 심즈 스타일 원형 메뉴: 쓰다듬기, 턱 긁어주기, 안아주기, 공놀이, 간식 주기, 밥 주기, 수건으로 닦기, 앉아!, 쉬게 하기. 동작은 줄을 서서 차례대로 해요.
- 욕구(배고픔, 기운, 재미, 애정, 청결), 기분, 그리고 가까워질수록 더 많은 것이 열리는 유대감.
- 공을 직접 던져 보세요. 마우스로 공을 잡아 휙 던지면 강아지가 물어 와요.
- 펫은 물에 젖고 진흙이 묻고, 몸을 털고, 햇볕에 말라요.
- **꾸미기:** 목걸이·방울 목걸이·반다나·나비넥타이·목도리, 리본·꽃핀·비니·밀짚모자·왕관, 스웨터·조끼·우비, 동그란 안경·선글라스를 여러 색으로
  입힐 수 있어요(펫 패널 → 👗 꾸미기, 또는 트레이 → 우리 아이들 → 펫 → 꾸미기). 모두 무료예요. 처음부터 4가지가 열려 있고, 나머지는 유대감이 쌓일수록
  열려요. "날씨에 맞춰 입히기"를 켜면 비 오면 우비, 눈 오면 목도리와 비니를 알아서 입고, 우비를 입은 펫은 비를 훨씬 덜 싫어해요. 반응도 품종마다
  달라서 말티즈나 페르시안은 신나 하고, 시바나 허스키는 몸을 털며 투덜대요.
- **꾸미기 장난과 커플룩:** 꾸미는 걸 싫어하는 펫은 가끔 머리를 흔들어 모자나 안경을 바닥에 벗어 던져요("벗었다! 자유다!"). 펫 패널의
  🎩 다시 씌워 주기로 다시 씌우거나, 10분이 지나면 다시 쓰게 돼요. 그 전에 장난기 많은 강아지가 먼저 주워 쓰고 우다다 뛰어다니다 다른 곳에
  떨어뜨리기도 해요. 같은 옷을 입은 펫끼리는(**커플룩**: 꾸미기 창의 "똑같이 입히기") 더 빨리 친해지고, 가끔 나란히 서서 "커플룩 어때?"
  "찰떡이지!" 하며 뽐내요.
- **원하는 색으로:** 펫마다 털, 배·가슴·발, 무늬, 눈 색을 추천 색이나 원하는 아무 색으로 바꿀 수 있어요(펫 패널 → 🎨 색 바꾸기, 또는 트레이 →
  우리 아이들 → 펫 → 색 바꾸기). 털의 음영은 함께 따라 바뀌고 품종 무늬는 그대로 남으며, "품종 원래 색으로"를 누르면 되돌아가요.

### 성장
새끼(0–14일) → 청소년(15–45일) → 성체(46–365일) → 노령(366일 이상). 컴퓨터 앞에 10분 있으면 하루로 쳐서, 컴퓨터를 꺼 둔 동안에는 나이를 먹지 않아요. 성장 단계를 넘을 때는 색종이와 고깔모자로 축하해요.

### 집
모양, 색, 장식을 골라 집을 세 채까지 지을 수 있어요. 집마다 주인을 정하거나 모두의 집으로 둘 수 있어요. 펫은 문으로 들어가 문간에 엎드려 밖을 내다보고, 잠에서 깨면 다시 나와요.

### 날씨
원하는 지역의 실제 날씨를 [Open-Meteo](https://open-meteo.com)에서 받아올 수 있어요(선택). 물보라가 튀는 비, 천둥과 번개, 쌓였다 녹는 눈, 구름과 안개. 펫은 성격대로 반응해요.

### 펫끼리 대화 (AI, 선택)
[Claude Code](https://claude.com/claude-code)가 설치되어 로그인되어 있으면, 마주친 펫들이 가끔 멈춰 서서 각자의 페르소나대로 수다를 떨어요. 품종 기질, 성격, 나이, 지금 기분, 입은 옷, 둘 사이의 관계가 반영돼요. 대사는 내 Claude가 써요(작고 빠른 모델, 몇 분에 한 번). 펫들이 서로 다가가 말풍선으로 번갈아 말하고, 다정한 대화를 나누면 더 친해져요. 트레이에서 끌 수 있고, Claude Code가 없으면 아무것도 달라지지 않아요.

### 낮과 밤
낮과 밤은 컴퓨터 시계와 내가 사는 곳의 실제 해 뜨고 지는 시간을 따라가요(날씨 지역 기준으로 컴퓨터에서 계산하고, 인터넷은 필요 없어요). 해 질 녘과 새벽엔 노을빛이 돌고, 밤에는 바탕화면이 짙은 파란색이 되며 맑은 밤엔 별이 뜨고, 집 창문에 불이 켜지고, 펫들은 졸려 해요.

### 가상 데스크톱
데스크톱마다 자기 바탕화면으로 만든 서식지가 있어요. 펫은 한쪽 끝으로 걸어 나가 옆 데스크톱 반대쪽 끝으로 들어와요. 데스크톱을 바꾸면 따라오거나(따라다니기), 마음대로 돌아다니거나(자유롭게), 집을 지키고(집 지키기), 트레이에서 불러올 수도 있어요.

### PetFam 바탕화면
**트레이 → PetFam 바탕화면**에서 PetFam이 직접 그린 바탕화면을 고를 수 있어요. **햇살 초원**(연못, 모래 오솔길, 진흙 웅덩이, 양지와 나무 그늘),
**바닷가**(바다, 모래사장, 바위 웅덩이, 야자수 그늘), **아늑한 정원**(잔디밭, 분수, 모래 놀이터, 텃밭, 파라솔). 그림과 함께 그린 정확한 서식지가
들어 있어서 펫이 분석 없이도 구석구석 다 알아요. **원래 바탕화면으로**를 누르면 전에 쓰던 그림으로 돌아가요(Windows 추천 사진(스포트라이트)을 쓰고 있었다면
설정에서 다시 켜야 해요).

### 서식지 편집기
바탕화면 분석은 대부분의 그림을 잘 읽지만 완벽하지는 않아요. 호수를 모래사장으로 읽거나, 펫이 올라갈 수 있어야 할 언덕을 놓치기도 해요.
**트레이 → 서식지 고치기**를 누르면 화면에 바탕화면 그림이 펼쳐지고, PetFam이 각 부분을 무엇으로 생각하는지 색으로 보여 줘요.
둥근 붓으로 그 위에 칠하세요: 바닥, 물, 진흙, 모래, 양지, 그늘, 바닥 아님. "되돌리기 (자동으로)"로 칠한 곳을 다시 지울 수 있어요.
마우스 휠로 붓 크기를 바꾸고, Ctrl+Z로 마지막 붓질을 취소해요. 저장하면 펫들이 바로 새 바닥을 써요. 고친 내용은 바탕화면 그림과 화면 크기별로
저장돼서, 그 바탕화면을 다시 쓰면 그대로 돌아와요.

### 여러 모니터
모니터마다 그 화면의 바탕화면 그림으로 만든 서식지가 있고, 모든 모니터가 펫의 세상이에요. 펫은 가끔 한 화면의 끝으로 걸어 나가 옆 모니터의 마주 보는 끝에서, 바닥의 같은 높이로 들어와요(집 지키기 펫은 자기 화면에 머물러요). 데스크톱을 바꾸면 따라오는 펫은 원래 있던 모니터로 들어와요. 모니터를 연결하거나 빼면 PetFam이 알아서 맞춰 다시 구성하고, 사라진 화면에 있던 펫은 주 모니터로 옮겨 와요. 밥그릇, 집, 새 펫은 주 모니터에 놓여요.

### 언어
기본은 영어, 한국어도 선택할 수 있어요(트레이 → Language / 언어). 품종 소개와 펫이 하는 말까지 전부 바뀌어요.

## PetFam 설치하기 (Windows)

Windows 10 또는 Windows 11 PC만 있으면 돼요. 다른 프로그램도, 관리자 비밀번호도 필요 없어요.

### 1. 설치 파일 받기
PetFam을 공유해 준 사람에게서 **`PetFam-Setup-1.0.0.exe`** 파일을 받아(메신저, 메일, 공유 드라이브 등) 예를 들어 **다운로드** 폴더에 저장하세요.

> 브라우저가 "일반적으로 다운로드되는 파일이 아닙니다"라고 할 수 있어요. Edge에서는 **⋯ → 유지**, Chrome에서는 **유지**를 누르세요.

### 2. 실행하기
**`PetFam-Setup-1.0.0.exe`**를 더블클릭하세요.

> **"Windows의 PC 보호" 창이 떴나요?** 아직 유료 게시자 인증서가 없는 새 앱에서 나타나는 파란 창이에요.
> **추가 정보**를 누른 다음 **실행**을 누르세요.

### 3. 설치 화면 따라가기
1. 언어를 고르고 **확인**을 누르세요.
2. **"Windows에 로그인하면 PetFam 자동으로 시작 (권장)"**은 체크된 채로 두세요. 그래야 PC를 켤 때마다 펫이 있어요.
   바탕화면에 아이콘을 두고 싶으면 **"바탕 화면에 바로 가기 만들기"**도 체크하세요.
3. **설치**, 그리고 **마침**을 누르면 PetFam이 바로 시작돼요.

1분도 안 걸리고, 관리자 권한도 묻지 않아요.

### 4. 첫 펫 입양하기
창이 열리면 **강아지나 고양이**를 고르고, **품종**을 고르고, 아기에게 **이름**을 지어 준 다음 **입양하기**를 누르세요.
펫이 창들 아래, 바탕화면에 나타나요.

### PetFam은 어디 있나요?
PetFam에는 큰 창이 따로 없어요. 화면 오른쪽 아래, 시계 옆 **트레이**에 살아요.
PetFam 아이콘(강아지와 고양이)이 안 보이면 거기 있는 작은 **^** 화살표를 누르세요.
아이콘을 누르면 메뉴가 나와요. 우리 아이들, 밥그릇, 집, 날씨, 언어, 그리고 **종료**.

종료한 뒤 다시 켜려면: **시작 메뉴 → PetFam**.

### 업데이트
새 `PetFam-Setup-x.y.z.exe`를 같은 방법으로 실행하세요. PetFam이 알아서 닫히고 업데이트되며, 펫들은 모두 그대로 있어요.

### 제거
**설정 → 앱 → 설치된 앱 → PetFam → ⋯ → 제거.**
다시 설치할 때를 위해 펫 데이터는 남겨 둬요(`%LOCALAPPDATA%\PetFam`). 데이터까지 지우려면 **Win + R**을 누르고 `%LOCALAPPDATA%\PetFam`을 입력해 Enter를 누른 뒤, 그 폴더를 삭제하세요.

### 설치 없이 쓰고 싶다면: 휴대용 버전
`PetFam-1.0.0-portable.zip`에는 설치 과정 없이 같은 앱이 들어 있어요. zip 파일을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 하고, 폴더를 열어 **PetFam.exe**를 더블클릭하세요. Windows와 함께 자동으로 시작되지 않고, 시작 메뉴에도 등록되지 않아요.

## PetFam 설치하기 (macOS)

macOS 11(Big Sur) 이상인 Mac이 필요해요.

1. Apple 실리콘(M1, M2, M3, M4) Mac이면 **`PetFam-1.0.0-macos-arm64.zip`**, 예전 Intel Mac이면
   **`PetFam-1.0.0-macos-x64.zip`**을 받으세요( → 이 Mac에 관하여에서 확인할 수 있어요).
2. zip 파일을 더블클릭해서 풀고 **PetFam**을 **응용 프로그램** 폴더로 끌어다 놓으세요.
3. 처음 한 번은 **PetFam을 마우스 오른쪽 버튼으로 눌러 → 열기**, 그리고 한 번 더 **열기**를 누르세요. (아직 App Store 앱이 아니라서
   macOS가 처음에 한 번 물어봐요. 취소만 할 수 있다면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누르세요.)
4. 첫 펫을 입양하세요. PetFam은 화면 오른쪽 위 **메뉴 막대**에 살아요(Dock 아이콘은 없어요). 강아지와 고양이 아이콘을 누르면 메뉴가 나와요.

로그인할 때 PetFam을 자동으로 켜려면: **시스템 설정 → 일반 → 로그인 항목 → +**에서 PetFam을 고르세요.
펫은 모든 Space(데스크톱)에 있고, Space를 바꾸면 따라와요. 펫 데이터는 `~/Library/Application Support/PetFam`에 있어요.

### PetFam 사용법
- **트레이 메뉴:** 우리 아이들(어디 있나, 부르기, 이동 방식), 날씨, 밥그릇 놓기, 새 집 짓기, PetFam 바탕화면, 서식지 고치기, 펫 추가하기, 언어, 종료.
- **마우스:** 펫 위에 올리면 앞으로 나와요. 누르면 메뉴가 열리고, 누른 채 문지르면 쓰다듬기, 끌면 안아서 옮겨요. 집을 누르면 꾸미기, 끌면 옮기기.
- **패널:** 펫을 누르면 기분, 욕구, 유대감, 나이, 할 일 목록이 담긴 패널이 열려요.

## 개인정보
- PetFam은 창의 위치, 마우스 포인터 위치, 자리 비움 시간만 읽어요. 창 안의 내용은 절대 읽지 않아요.
- 바탕화면 그림은 내 컴퓨터에서 분석하고, 아무것도 업로드하지 않아요.
- 유일한 인터넷 요청은 선택 사항인 날씨 조회이고, 고른 도시의 좌표만 보내요(IP 조회도, 위치 권한도 없어요). 트레이에서 끌 수 있어요.
- AI 대화(Claude Code가 설치된 경우만)는 두 펫의 이름, 품종, 성격, 기분, 옷, 날씨와 시간대, 지난번에 나눈 말을 내 Claude에 보내요. 화면 내용은 보내지 않아요. 트레이에서 끌 수 있어요.

## 개발자용

필요한 것: Windows 10 21H2 이상과 [.NET 8 SDK](https://dotnet.microsoft.com/download).

```
dotnet build PetFam.sln
dotnet test
dotnet run --project src/PetFam.App
```

### 설치 파일 빌드

```
powershell -ExecutionPolicy Bypass -File build\build-installer.ps1
```

PetFam을 .NET 없이 실행되는 `PetFam.exe` 한 개로 게시하고, Inno Setup으로 `installer\PetFam.iss`를 컴파일하고, 휴대용 zip을 만들어요. 결과는 `artifacts\`에 생겨요: `PetFam-Setup-<버전>.exe`, `PetFam-<버전>-portable.zip`. 버전은 `Directory.Build.props`에서 가져와요(또는 `-Version 1.2.0`).
Inno Setup 컴파일러는 `INNO_ISCC`, 설치된 Inno Setup 6, 또는 `Tools.InnoSetup` NuGet 패키지에서 `.tools\`로 한 번 내려받은 것을 써요.

설치 프로그램은 사용자별로 `%LOCALAPPDATA%\Programs\PetFam`에 설치하고(관리자 권한 요청 없음), 시작 메뉴에 등록하고, 선택에 따라 바탕화면 바로 가기와 로그인 시 자동 시작을 추가해요. `%LOCALAPPDATA%\PetFam`의 펫 데이터는 절대 건드리지 않아요.
PetFam은 한 번에 하나만 실행돼요. 두 번째로 실행한 것은 바로 종료돼요(`PETFAM_MULTI=1`이면 여러 개 허용, 개발용 시트용).

**macOS:** Mac에서 `bash build/build-macos.sh`를 실행하면 Apple 실리콘용과 Intel용으로 게시하고, 각각 `PetFam.app`(메뉴 막대 앱, Dock 아이콘 없음,
`installer/macos/Info.plist`)으로 감싸 임시(ad hoc) 서명한 뒤 zip으로 만들어요. macOS 계층(`src/PetFam.Platform.MacOS`)은 시스템과 직접 대화해요.
뒷마당은 모든 Space에서 바탕화면 그림 바로 위에 있는 창이고, 전면 창은 CGWindowList에서(창의 사각형만, 손쉬운 사용 권한 불필요), Space는 윈도 서버에서 읽어요.

**자동 빌드:** `v1.0.0` 같은 태그를 푸시하면 GitHub Actions에서 `.github/workflows/release.yml`이 실행돼요. 테스트를 돌리고 Windows 설치 파일과 휴대용 zip, macOS zip 두 개를 만들어 초안(Draft) 릴리스에 올려요. Actions 탭에서 직접 실행할 수도 있고, 이때는 파일이 실행 결과의 아티팩트에 있어요.

아직 코드 서명이 되어 있지 않아서 처음 실행할 때 Windows SmartScreen 경고가 떠요(위 설치 단계 참고). 코드 서명 인증서로 exe와 설치 파일에 서명하면 경고가 사라져요.

```
src/PetFam.Core              플랫폼 독립: 펫, 품종, 욕구, 유대감, 성장, 서식지, 행동, 날씨, 저장
src/PetFam.Platform.Windows  Win32: WorkerW 바탕화면 층, 클릭 통과, 전면 창, 가상 데스크톱
src/PetFam.Platform.MacOS    스텁(계획 중)
src/PetFam.App               Avalonia 앱: 창, 트레이, 3D(SkSL SDF)와 벡터 렌더러, 날씨 서비스
tests/PetFam.Core.Tests      xUnit
build/wallpapers             PetFam 바탕화면과 서식지 지도를 그리는 스크립트(python -I build/wallpapers/make_wallpapers.py)
docs/PLANNING.md             제품·기술 기획(영어)
```

- 데이터: `%LOCALAPPDATA%\PetFam\save.json`(1분마다, 그리고 종료할 때 저장), 서식지 고친 내용 `habitat-edits.json`, 로그 `petfam.log`, 스냅샷과 디버그 시트. 예전 `ZooZoo` 폴더의 데이터는 처음 실행할 때 복사돼요.
- 프레임 타이밍: 애니메이션이 끊기면 `petfam.log`에 무엇이 시간을 잡아먹었는지 `Hitch:` 줄로 남아요.

### 진단용 환경 변수

| 변수 | 효과 |
|---|---|
| `PETFAM_NO_PEEK=1` | 빼꼼 내밀기를 끔(유대감 단계 조건은 그대로) |
| `PETFAM_CALM_FPS=<n>` | 한가할 때 프레임 수(기본 12) |
| `PETFAM_PAINT_WALLPAPER=1` | 바탕화면 그림을 뒷마당 창에 직접 그림(투명이 안 될 때의 대안) |
| `PETFAM_NO_ATTACH=1` | WorkerW에 붙지 않고 일반 창을 씀 |
| `PETFAM_RENDER=software\|angle\|wgl` | Avalonia 렌더 백엔드를 강제 |
| `PETFAM_COMP=winui\|dcomp\|redirect` | Avalonia 합성 모드를 강제 |
| `PETFAM_UI_RENDER=1` | UI 스레드에서 렌더링 |
| `PETFAM_SNAPSHOT=1` | 시작 후 모니터마다 뒷마당 스냅샷을 자동 저장(`PETFAM_SNAPSHOT_DELAY=<초>`, 기본 3). PetFam이 그린 것만 담김 |
| `PETFAM_STYLE=fur` | 카툰 대신 털 질감 3D 스타일로 그림 |
| `PETFAM_WALLPAPER=<이미지 경로>` | 실제 바탕화면은 그대로 두고 이 이미지를 뒷마당에 깔아 서식지 인식과 행동을 시험 |
| `PETFAM_ADOPT=cat,dog,shiba,…` | 시작할 때 펫을 더 데려옴: `cat`, `dog` 또는 품종 id(`pomeranian` `maltese` `poodle` `bichon` `shiba` `corgi` `jindo` `korean-shorthair` `russian-blue` `british-shorthair` `scottish-fold` `persian` `ragdoll` `munchkin` `golden-retriever` `french-bulldog` `dachshund` `siberian-husky` `chihuahua` `beagle` `samoyed` `border-collie` `shih-tzu` `pug` `siamese` `maine-coon` `bengal` `sphynx` `abyssinian` `american-shorthair` `norwegian-forest` `turkish-angora` `exotic-shorthair`). 저장됨 |
| `PETFAM_SHOW_HABITAT=1` | 인식한 바닥을 초록색, 지평선을 노란 선으로 화면에 표시(트레이의 "(테스트) 서식지 인식 결과 보기"로도 전환) |
| `PETFAM_BOND=<0~100>` | 시작할 때 모든 펫의 유대감을 이 값으로(트레이 "(테스트) 유대감"으로도 조절) |
| `PETFAM_DEMO_MENU=menu\|queue` | 시작 4초 뒤 첫 펫의 원형 메뉴를 자동으로 엶(queue: 할 일 몇 개를 미리 채움) |
| `PETFAM_POSE_SHEET=1` | 시작할 때 모든 자세를 한 장에 그린 `pose-sheet.png` 저장(리그 확인용) |
| `PETFAM_TURN_SHEET=cat\|dog` | 자세 × 10방향을 한 장에 그린 `turn-sheet.png` 저장(옆·뒷모습 확인용) |
| `PETFAM_MOTION_SHEET=cat\|dog` | 돌아서기, 출발, 걷기, 멈추기, 앉기, 일어나 달리기를 30fps로 움직여 차례로 그린 `motion-sheet.png` 저장(동작 전환 확인용) |
| `PETFAM_DEMO=ball` | 실행 3초 뒤 첫 강아지와 공놀이 시작(던지기 확인용) |
| `PETFAM_DEMO=house` | 실행 3초 뒤 새 집 짓기 창을 엶 |
| `PETFAM_FAKE_HOVER=1` / `primary` / `mon-X-Y` | 마우스를 움직이지 않고, 가상 커서를 화면의 첫 펫(또는 그 모니터의 펫) 위에 올려 둠. `PETFAM_FAKE_HOVER_BLINK=1`이면 1초마다 펫 위에 올렸다 뗐다 함 (마우스 올리기 확인용) |
| `PETFAM_TRACE_HOVER=1` | 커서 밑에서 펫이 앞 창으로 들어가고 나올 때마다, 그리고 커서가 바탕화면에 올라가고 벗어날 때마다 로그에 남김 |
| `PETFAM_FAST_TALK=1` | 펫끼리 대화(AI)를 4~8분 대신 30~45초마다 |
| `PETFAM_AI=off` | AI 대화 끄기: Claude CLI를 찾지 않음 |
| `PETFAM_CLAUDE=<경로>` | PATH에서 찾은 것 대신 이 `claude` 실행 파일로 AI 대화 |
| `PETFAM_DEMO=habitat` / `habitat2` | 실행 4초 뒤 주(또는 두 번째) 모니터에 서식지 편집기를 열고 그 모습을 `habitat-editor.png`로 저장 |
| `PETFAM_DEMO=dropped` | 실행 3초 뒤 모자와 안경을 종류별로 바닥에 놓음(모습 확인용) |
| `PETFAM_DEMO=outfit` | 실행 4초 뒤 첫 펫의 꾸미기 창을 열고 그 모습을 `outfit-editor.png`로 저장 |
| `PETFAM_DEMO=colours` | 실행 4초 뒤 첫 펫의 색 바꾸기 창을 열고 그 모습을 `coat-editor.png`로 저장 |
| `PETFAM_DEMO=monitor` | 실행 3초 뒤 첫 펫이 옆 모니터로 걸어감 |
| `PETFAM_DEMO=travel` | 실행 3초 뒤 첫 펫이 옆 데스크톱으로 걸어 나가고, 14초 뒤 다시 불러옴 |
| `PETFAM_BREED_SHEET=1` | 모든 품종을 성체로 두 방향씩 그린 `breed-sheet.png` 저장 |
| `PETFAM_ONBOARDING=1` / `cat` | 시작할 때 입양 창을 엶(`cat`: 고양이 탭) |
| `PETFAM_TIME=HH:mm` | 그 시각인 것처럼 함(트레이: 날씨 → (테스트) 시간대 바꿔 보기) |
| `PETFAM_CLOSEUP_SHEET=1` | `PETFAM_CLOSEUP_BREEDS`(품종 id, 쉼표 구분)의 품종을 크게 그린 `closeup-sheet.png` 저장(얼굴과 털 확인용) |
| `PETFAM_CLOSEUP_POSE=walk` / `PETFAM_CLOSEUP_COAT=F2A9C4,,,4F86D6` | 근접 시트의 자세와 고른 색(털, 밝은 부분, 무늬, 눈; 16진수, 비워 둬도 됨) |
| `PETFAM_CLOSEUP_OUTFIT=head:beanie:3C8DDE,body:sweater:F2A9C4` | 근접 시트의 모든 펫에게 옷을 입힘(부위:아이템:색, 쉼표로 구분) |
| `PETFAM_TURN_POSES=pant,yawn,…` | `PETFAM_TURN_SHEET`의 기본 자세 대신 쓸 자세 |
| `PETFAM_LANG=en` / `ko` | 그 언어로 시작(저장된 선택보다 우선) |
| `PETFAM_WEATHER=<날씨>` | 실제 날씨 대신: `clear`, `cloudy`, `fog`, `drizzle`, `rain`, `heavyrain`, `thunder`, `snow`, `heavysnow`(눈이 이미 쌓인 상태) |
| `PETFAM_DOOR_SHEET=1` | 문으로 집에 들어가기, 안에서 자기, 창 가장자리 빼꼼 단계를 그린 `door-sheet.png` 저장(고양이와 강아지, 네 방향) |
| `PETFAM_DEMO=grow` | 실행 4초 뒤 (선택한 펫, 없으면 모든 펫을) 다음 성장 단계로 |
| `PETFAM_AGE_DAYS=<일>` | 시작할 때 모든 펫의 함께한 날을 이 값으로 |
| `PETFAM_GROWTH_SHEET=1` | 고양이와 강아지를 0일부터 500일까지 나이별로 그린 `growth-sheet.png` 저장 |
| `PETFAM_SAVE=<파일>` | 다른 저장 파일을 씀(파일이 없으면 첫 실행 입양부터 시작, 실제 펫은 그대로) |
